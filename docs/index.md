# LLMoxie Analysis

**llmoxie-analysis** is the data analysis package for the
[LLMoxie](https://github.com/uw-ssec/llmoxie) project. It turns raw LLMoxie
gateway request logs into a queryable Parquet warehouse of sessions, messages,
and tool calls.

!!! note "Early days"

    The package is in active development and these docs are a starting point.
    Pages are added as features land.
